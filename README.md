# نظام حجز الفنادق — سفريات القلعة للسياحة والسفر

نظام داخلي لموظفي سفريات القلعة لحجز الفنادق من أكثر من شركة مورّدة، على `hotels.alqalaatravels.net`.

## الأقسام
- **البحث والحجز:** بحث في كل الشركات المفعّلة دفعة واحدة، ونتائج مدموجة بأفضل سعر بدون اسم الشركة. السعر محجوز 10 دقائق، ويُعاد طلب الشروط تلقائياً بعدها.
- **الحجوزات والقسائم:** بحث وفلترة، وقسيمة العميل (طباعة / PDF / بريد / واتساب)، وقراءة الحجز من الشركة، وإلغاؤه.
- **الشركات الموردة و API:** إضافة الشركات وتفعيلها وإيقافها، واختبار الاتصال، وتحديث قائمة الفنادق، ومفاتيح API للموقع.
- **الحسابات (للمحاسب والمدير):** هامش الربح العام ولكل شركة، وأسعار الصرف، ومكافآت الموظفين، وتقرير المحاسب مع تصدير Excel.
- **الموظفون:** إضافة وتعديل وإيقاف، والرقم المدني والبريد إلزاميان، وطلبات استرجاع الرقم السري.
- **الصلاحيات:** صفات مع صلاحيات قابلة للتعديل، وإضافة صفات جديدة. المدير يملك كل الصلاحيات دائماً.

## التشغيل على جهازك
```
npm install
npm start
```
ثم افتح http://localhost:3000. الدخول الأول: `admin` / `Admin@12345` (يُطلب تغييره فوراً).

## الرفع على Render (عبر GitHub)
1. ارفع المجلد على مستودع جديد في GitHub (مثلاً `alqalaa-hotels`).
2. في Render: **New → Blueprint** واختر المستودع. ملف `render.yaml` ينشئ الخدمة مع قرص دائم لقاعدة البيانات.
3. في **Environment** أضف القيم الموجودة في `.env.example` (خصوصاً `ADMIN_*` و`SMTP_*`).
4. في **Settings → Custom Domains** أضف `hotels.alqalaatravels.net`، ثم أضف سجل CNAME عند مزوّد النطاق كما يطلب Render.

> مهم: قاعدة البيانات SQLite تحتاج **قرصاً دائماً** (Disk) على Render، وهذا متاح في الخطة المدفوعة (Starter فما فوق). بدون قرص تُمسح البيانات مع كل تحديث.

## ربط عطوني (Juniper)
1. من **الشركات الموردة** عدّل «عطوني»: عنوان الربط، والبريد، والرقم السري (يُحفظ مشفراً)، والبيئة UAT.
2. اضغط **اختبار الاتصال**، ثم **تحديث الفنادق** (لازم كل 15 يوماً على الأقل).
3. فعّل الشركة، وأوقف «المورّد التجريبي أ/ب».
4. ملف `src/suppliers/juniper.js` مكتوب حسب التوثيق العام، ويُضبط نهائياً مع ملف SoapUI من عطوني قبل الاعتماد (Certification).

## API لموقع السفريات
كل طلب يحمل `X-API-Key`. الطلبات: `POST /api/v1/hotels/search` ← `POST /api/v1/hotels/rules` ← `POST /api/v1/hotels/book`، و`GET /api/v1/bookings/:ref`، و`POST /api/v1/bookings/:ref/cancel`.
